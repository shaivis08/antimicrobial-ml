## EDA Findings

- Dataset contains 129 observations after filtering for reported inhibition zones.
- 107 observations are in the training set and 22 in the test set.
- Inhibition zone ranges from 0–40 mm.
- The target distribution is moderately right-skewed.
- Several features were identified for further investigation due to low variance/redundancy.
- Regression was selected as the primary formulation because inhibition zone is continuous.
